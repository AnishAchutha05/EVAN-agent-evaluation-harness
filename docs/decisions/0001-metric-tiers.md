# 0001 - Metric tiers
- PRIMARY (5, always on): TSR, EPI, OCS, AMR, IL
- SECURITY (8, opt-in): IPR, SRR, TBR, EER, SCR, UCR, MPC, ADR
- QUALITY (1, opt-in): Hallucination Rate
- DIAGNOSTIC (not a metric): Fault Propagation Depth
Default runs report PRIMARY only, matching the approved project report.
